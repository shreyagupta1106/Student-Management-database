# SQL Data Analysis Internship - Task 1

## Project Overview

This project is a Student Management Database developed using SQL. The database stores student information and performs various data analysis operations to evaluate student performance.

## Objectives

* Create and manage a student database.
* Store student academic records.
* Perform data analysis using SQL queries.
* Generate insights from student performance data.

## Technologies Used

* SQL
* MySQL

## Database Operations

1. Create Students table
2. Insert student records
3. Display all student details
4. Calculate average scores in each subject
5. Identify the top-performing student
6. Count students by grade
7. Analyze average scores by gender
8. Filter students based on marks
9. Update student records

## Files Included

* student_management.sql : Contains all SQL queries.
* screenshots/ : Contains screenshots of query execution and outputs.
